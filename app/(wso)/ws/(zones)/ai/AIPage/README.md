# AIPage

UI orchestration for the `/ws/ai` conversation experience.

## Files
- `index.tsx`: thin chat-page orchestrator and local motion sequencing.
- `MessageBubble.tsx`: text bubble rendering for user and assistant messages.
- `MessageRow.tsx`: conversation row wrapper with avatars and optional component payloads.
- `TypingIndicator.tsx`: branded typing state row.
- `CommandBar.tsx`: suggestions, input, and branded send control.
